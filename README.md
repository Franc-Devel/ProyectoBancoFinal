# Francis Bank · Maquetación bancaria

Proyecto educativo de interfaz bancaria. Presenta páginas HTML y estilos; no incluye un servidor bancario ni operaciones financieras reales.

## Alcance

Proyecto de formación. El contenido disponible puede consultarse en [Banco/index.html](Banco/index.html) y [Banco/css/styles.css](Banco/css/styles.css). No se presenta como un producto listo para uso comercial.

## Ejecución local

```bash
git clone https://github.com/Franc-Devel/ProyectoBancoFinal.git
cd ProyectoBancoFinal
python3 -m http.server 8000
```

Abrir `http://localhost:8000/Banco/index.html`. El servidor estático sólo sirve archivos; no implementa una API ni envía formularios a un servicio.
